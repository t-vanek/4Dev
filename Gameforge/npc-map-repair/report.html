Oprava map NPC a rozhovorů

Oprava je nasazená. NPC 22424–22433 nyní patří na mapu 12. Mapový server byl znovu spuštěn a načetl 2 755 NPC a 6 419 questů.

Server měl těchto deset NPC na mapě 11, a proto odmítal související požadavky z mapy klienta. Původní i současný klient shodně potvrzují mapu 12. Podrobný test navíc odhalil odpovědi s NPC ID 0, které klient ignoroval; server nyní vrací ID příslušného NPC.

Ověření

Prošlo 1 194 serverových testů. Testy proti nasazené serverové DLL zkontrolovaly obsah všech deseti odpovědí i zachování mapových a questových podmínek. Všechny 2 755 NPC odpověděly na rozhovor a nabídku questů; prošlo také dokončení 48 doručovacích/rozhovorových úkolů včetně Přihlášení k výcviku u Gripana.

Porovnání všech 2 755 NPC potvrdilo pouze deset zamýšlených změn pole wMapID. Kontrolní součty 202 dalších herních a 69 globálních tabulek zůstaly shodné; výjimkou je nový záznam o migraci. Oprava prošla opakovaným použitím a odmítnutím konfliktního vstupu s návratem testovacích změn.

Rozsah

Testovací postavy a běžící předchozí quest 4558 byly pouze v paměti. Testy nezapisovaly hráčům questy, předměty ani odměny. Grafický průchod celou kapitolou neproběhl. Další závislosti z celkového auditu zůstávají samostatnými nálezy.

Podrobnosti: výsledky a nasazení, zdroje a původní hodnoty, test deseti NPC, regresní test NPC a questů.
